BRIGHTPATH REDESIGNED WEBSITE

This is a redesigned version of the multi-page teacher template.
The original multi-file structure and image/vendor assets are retained.
The visual theme has been changed to a purple, lilac, orange and white palette,
with new typography, updated branding, hover effects and entrance animations.

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted BrightPath-Redesigned folder in Visual Studio Code.
3. Open index.html with Live Server (recommended).
4. Use the navigation menu to visit the other pages.

IMPORTANT
- Keep the assets folder in the same location as the HTML files.
- Do not move the HTML files away from the assets folder.
- Internet is needed to load the Google Fonts; the site otherwise uses local assets.
- Pages included: index, about, courses, course-details, events, trainers, pricing,
  contact and starter-page.
